# UniST

Retrieve the pinned implementation from [UniST](https://github.com/tsinghua-fib-lab/UniST) using the repository-root command:

```bash
python tools/fetch_baselines.py --models UniST
python tools/fetch_baselines.py --models UniST --check
```
